These are Demos that show how to use IntraWeb.

Guess
This demo shows basic data binding, event handling, and simple state management.

StorageDemo
This demo shows how to persist data in the browser's localStorage. Enter a
name and press Save; reload the page and it remembers you. Named
StorageDemo (not LocalStorage) because IntraWeb resolves the page's code
class by a case-insensitive scan of window properties, and a namespace
named LocalStorage collides with the browser's built-in window.localStorage.
